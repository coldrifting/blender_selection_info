# blender_selection_info
Blender addon which adds buttons to quickly export mesh data for use in config files with [KSP PBR Patcher](https://github.com/coldrifting/KSP_PBR_Patcher)

## Install
* Download the repository source code as a ZIP file
* In Blender, Open File > Preferences
* In the Add-ons tab, Click Install, and select the downloaded ZIP file
* Done!

## Usage
* Import a .mu mesh you'd like to get info for
* Select the relevant mesh in edit mode, either in vertex mode or face mode
* Press `N` to toggle the sidebar if it is not open
* Under the item tab, press a relevant button under `Selection Info` to copy the relevant data to the clipboard
* Done! The data is preformatted and ready to use in a YAML config file with the PBR patcher
